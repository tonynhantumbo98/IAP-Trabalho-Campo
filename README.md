# Sistema de Gestão de Biblioteca

## Descrição

Sistema desenvolvido em Java para gerir livros e empréstimos de uma biblioteca através da consola.

## Funcionalidades

- Registo de livros
- Consulta de catálogo
- Pesquisa por título
- Pesquisa por autor
- Empréstimos
- Devoluções
- Estatísticas

## Requisitos

- Java JDK 8 ou superior

## Compilação

javac Biblioteca.java

## Execução

java Biblioteca
